Example: Offline Favorites Sync

FF Designer built the list UI and heart toggles. You need offline fallback.

ALREADY IN FF DESIGNER

Favorites list with pull-to-refresh

Heart-button toggle (Firestore write)

FavoriteSong data type in FF

WHAT'S MISSING

Offline access when no network

Local cache of favorites

Graceful Firestore failure handling

YOUR PROMPT:

Create a Custom Action called SyncFavoritesToLocal that reads the current user's "favorites" subcollection from Firestore, serializes each doc into a FavoriteSong struct (songId String, title String, artist String, addedAt DateTime), stores the list in shared_preferences as JSON under "cached_favorites". Return the count as int. If Firestore is unreachable, load from cache instead.
