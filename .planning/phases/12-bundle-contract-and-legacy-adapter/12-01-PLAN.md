# Phase 12 Plan 01: Bundle Contract, Helpers, and Fixtures

## Goal

Create the canonical `artifactBundle` model as pure JavaScript helpers with fixture tests that do not require live AI, DOM, or FlutterFlow API access.

## Requirements

- BUND-01
- BUND-02
- BUND-03
- BUND-04
- PIPE-04
- FIXT-01

## Tasks

1. Add a pure helper module for bundle normalization.
   - Define default bundle shape.
   - Define artifact normalization defaults.
   - Add deterministic artifact id fallback from artifact type and artifact name.
   - Add bundle-level dependency and relationship normalization.

2. Add fixture tests.
   - Single-widget fixture normalizes to one-artifact bundle.
   - Mixed-artifact fixture preserves ids, metadata, dependencies, and relationships.
   - Legacy string/code fallback normalizes to a one-artifact bundle with warnings.

3. Add a test script.
   - Use Node's built-in test runner.
   - Keep tests local and side-effect free.

## Verification

- `npm test` passes.
- Fixture tests prove stable ids, metadata defaults, relationship metadata, and fallback warnings.
