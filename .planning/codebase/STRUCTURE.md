# Codebase Structure

**Analysis Date:** 2025-02-13

## Directory Layout

```
dreamflowCommandForFlutterFlow/
├── app.js              # All application logic (~2000 lines)
├── index.html          # UI structure and Tailwind styles
├── vite.config.js      # Dev server config with API proxies
├── package.json        # Project manifest
├── package-lock.json   # Dependency lockfile
├── .env.example        # Environment variable template
├── .env                # Local API keys (gitignored)
├── AGENTS.md           # Developer guide for AI agents
├── README.md           # User documentation
├── CCC-Home.mp4        # Tutorial video asset
├── sidebar-header.png  # UI asset
├── dist/               # Build output (generated)
│   ├── index.html
│   └── assets/
├── public/             # Static assets
└── node_modules/       # Dependencies
```

## Directory Purposes

**Root Files:**
- `app.js` - Main application logic (~2000 lines)
  - Contains all functions, API clients, state management
  - No module splitting (monolithic)
- `index.html` - UI structure and styling
  - Tailwind CSS classes embedded
  - Modal templates and walkthrough HTML
- `vite.config.js` - Vite configuration
  - API proxy routes for Gemini/Anthropic/OpenAI
  - Dev server settings (port 3000)
- `AGENTS.md` - Developer documentation
  - Architecture overview
  - Code style guidelines
  - FlutterFlow-specific rules

**dist/** (Generated):
- Purpose: Production build output
- Contains: Bundled HTML and assets
- Committed: No (should be .gitignored but present)
- Source: Generated by `npm run build`

**public/**:
- Purpose: Static assets served as-is
- Contains: Publicly accessible files

**node_modules/**:
- Purpose: npm dependencies
- Committed: No (.gitignored)

## Key File Locations

**Entry Points:**
- `index.html` - Browser entry point
- `app.js` - JavaScript entry point (loaded via module script)

**Configuration:**
- `vite.config.js` - Build and dev server configuration
- `package.json` - npm scripts and metadata
- `.env.example` - Environment variable documentation

**Core Logic:**
- `app.js` - Contains ALL application logic:
  - `runThinkingPipeline()` - Main orchestration
  - `runPromptArchitect()` - Step 1
  - `runCodeGenerator()` - Step 2
  - `runCodeDissector()` - Step 3
  - API client functions (Gemini, Claude, OpenAI)
  - Encryption utilities
  - Walkthrough logic

**Documentation:**
- `README.md` - User-facing documentation
- `AGENTS.md` - Developer/agent documentation

**Assets:**
- `CCC-Home.mp4` - Tutorial video
- `sidebar-header.png` - UI header image

## Naming Conventions

**Files:**
- kebab-case: `vite.config.js`, `index.html`
- Descriptive names: `app.js` (contains all app logic)

**Functions (in app.js):**
- camelCase: `runCodeGenerator`, `callGemini`
- Verb-first: `showWalkthroughIfNeeded`, `updateWalkthroughUI`
- Handler prefix: `handleWelcomeVideoEnd`, `dismissWelcomeVideo`

**Variables:**
- camelCase: `pipelineState`, `geminiApiKey`
- UPPER_SNAKE_CASE for constants: `PROMPT_ARCHITECT_MODEL`

**HTML IDs:**
- kebab-case: `walkthrough-modal`, `pipeline-input`

## Where to Add New Code

**New Pipeline Step:**
- Implementation: `app.js` - Add new async function
- UI: `index.html` - Add step UI and workflow item
- Integration: Wire into `runThinkingPipeline()`

**New API Integration:**
- Client function: `app.js` - Add `callNewAPI()` function
- Proxy config: `vite.config.js` - Add proxy route
- Environment: `.env.example` - Document new key

**New UI Components:**
- Structure: `index.html` - Add HTML templates
- Logic: `app.js` - Add event handlers and render functions
- Styling: Use Tailwind classes in HTML

**Utilities:**
- Add to `app.js` (monolithic structure)
- Export to `window` if needed for HTML onclick handlers

## Special Directories

**dist/**:
- Purpose: Production build artifacts
- Source: Generated by Vite (`npm run build`)
- Committed: Present but should be gitignored
- Note: Contains bundled/minified versions
